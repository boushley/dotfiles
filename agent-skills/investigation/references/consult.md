# Consult

Read the full investigation artifact before answering. Use it as the default evidence boundary.

Answer the user's question directly and briefly. Cite finding, dispute, or source identifiers when they help the user trace the answer. State when an answer is an inference from the artifact rather than a recorded conclusion. Surface relevant uncertainty or disagreement without reciting the whole artifact.

If the artifact cannot support an answer, explain:

1. what it does establish;
2. the exact missing evidence; and
3. a bounded research task likely to close the gap.

Ask for confirmation before opening sources, searching the web, inspecting unrelated repository material, or doing other research outside the artifact. After approval, follow [investigate.md](investigate.md), merge the result into the artifact, and then answer the question.

## Save conversation results

Edit the artifact only when the user asks with language such as "add that to the doc," "capture this," or "summarize this thread in the doc." Resolve what "that" refers to from the conversation; ask only if the target is materially ambiguous.

Distill the useful conclusions, decisions, reasoning, corrections, and open questions into the relevant sections. Do not append a transcript. Label user-provided conclusions and conversation-derived inferences so they do not appear to be externally sourced facts. Reconcile conflicts and repetition using [artifact.md](artifact.md), then report what changed.
