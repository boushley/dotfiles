# Investigate

## Establish the brief

Read any existing artifact and use context the user already supplied. Ask one compact batch of qualifying questions, usually no more than five. Cover only gaps that affect the work, such as:

- the questions or decisions the investigation should support;
- relevant background, starting assumptions, and representative questions;
- scope boundaries, time period, and whose perspectives matter;
- required source types, freshness, or standards of proof;
- the artifact path when neither the user nor repository instructions supplied it.

Favor useful context over repeated refinement. Ask follow-ups only when an answer would materially change the research. Summarize the proposed scope, questions, and exclusions, then get the user's confirmation before beginning substantial research.

When consultation mode already obtained approval for a bounded research task, treat that approved proposal as the confirmed brief. Ask only for information still needed to perform it.

## Research

Research the confirmed questions against the best available evidence. Prefer primary sources, but use strong secondary sources when they add analysis, testimony, synthesis, or context. Trace consequential claims to the source that can support them.

Follow evidence that changes the working model. Investigate credible competing interpretations far enough to explain their evidence, assumptions, participants, and disagreements. Avoid collecting sources that merely repeat established points.

Stop when:

- every agreed question has a supported answer or an explicit `unknown`;
- material claims link to sources;
- credible competing interpretations and material limits are represented;
- remaining open questions say what evidence would resolve them; and
- additional credible sources mostly repeat what the artifact already captures.

## Reconcile the artifact

Write or update the artifact using [artifact.md](artifact.md). Revise affected sections rather than appending a research log. Merge duplicates, correct superseded statements, and keep stable identifiers. Preserve a superseded interpretation only when its history still explains a live disagreement or decision.

Before finishing, check that a new agent could answer the confirmed questions from the artifact without reopening sources. Report the artifact path, the questions answered, and any important unknowns.
